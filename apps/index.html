Murmur

Get Murmur on your phone

Same sign-in and music everywhere. You’ll need the name and 4-digit PIN the owner gave you.

Windows App

Download Murmur for Windows
  1. Run Murmur-Setup.exe. If Windows says Windows protected your PC, click More info → Run anyway (the app isn’t from the Microsoft Store).
  2. It installs in a few seconds, opens Murmur and adds a desktop shortcut. Sign in.

Media keys and the Windows media pop-up (cover, play/pause, skip) work. Closing the window quits Murmur. When there’s a new version, Murmur asks you to update.

Android APK

Download Murmur.apk
  1. Open the downloaded file. Android asks to allow installing apps from this source; allow it.
  2. If Play Protect warns about an unknown developer, tap More details → Install anyway.
  3. Open Murmur and sign in.

Motorola Razr: to use Murmur on the outside screen, turn it on in Settings → External display → Apps.

iPhone Sideload

Quickest way: open Murmur in Safari, tap Share → Add to Home Screen. It works like an app, with no computer needed.

For the real app file, you need a Windows PC or Mac and a USB cable:

Download Murmur.ipaGet Sideloadly
  1. On the computer, install iTunes (from apple.com, not the Microsoft Store) and Sideloadly.
  2. Plug in the iPhone and tap Trust on the phone.
  3. Open Sideloadly, drag in Murmur.ipa, type your Apple ID email, click Start, and enter your Apple ID password when asked.
  4. On the iPhone: Settings → General → VPN & Device Management, tap your Apple ID, then Trust.
  5. iOS 16 or newer: Settings → Privacy & Security → Developer Mode, turn it on, and restart when asked.

With a free Apple ID the app stops opening after 7 days. Plug in and click Start in Sideloadly again to renew it; your sign-in and songs stay.

Ad blocker for Safari

The Murmur app blocks YouTube ads by itself. To also block them when you use Murmur in Safari, the app (version 1.6 or newer) brings a Safari extension:

  1. Install the app with Sideloadly as above.
  2. On the iPhone: Settings → Apps → Safari → Extensions (older iOS: Settings → Safari → Extensions), tap Murmur Ad Blocker and turn it on.
  3. Under Permissions, set youtube-nocookie.com and youtube.com (or All Websites) to Allow.
  4. Open Murmur in a Safari tab. Ads are removed from YouTube songs.

Safari extensions don’t run in pages added to the Home Screen, so for ad-free YouTube songs use the Murmur app or a Safari tab.

Computer browser Ad blocker

Using Murmur in Chrome, Edge or Brave on a computer? The Murmur Ad Blocker removes ads from YouTube songs. It only acts inside Murmur. The phone apps already have it built in.

Download murmur-adblock.zip
  1. Unzip the file.
  2. Open chrome://extensions (Edge: edge://extensions) and turn on Developer mode.
  3. Click Load unpacked and pick the unzipped folder.
  4. Reload Murmur. Your account menu shows YouTube ad blocker: On.

Already have it? Updates to Murmur show up in the apps automatically; you only reinstall when this page says there’s a new app version.
